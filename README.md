# Проект go.cmd — обработка GPS-треков и создание KML

## Состав проекта

- `go.cmd` — основной пакетный скрипт Windows для обработки GPS-логов (`.log`) и создания KML-файлов.
- `gpsbabel.cmd` — вспомогательный скрипт-обёртка для запуска `gpsbabel.exe` с параметрами из командной строки.
- `csvfix.cmd` — вспомогательный скрипт, создающий символическую ссылку на `gpsbabel.exe` при первом запуске.

## Требования

- Windows
- GPSBabel (устанавливается в `C:\Program Files (x86)\gpsbabel` или `C:\Program Files\GPSBabel`)
- CSVfix (утилита `csvfix.exe` для обработки CSV)
- Папка `bin` в каталоге проекта со скриптами `gpsbabel.cmd` и `csvfix.cmd`
- Исходные GPS-логи в формате `.log` (или ином, поддерживаемом GPSBabel)

## csvfix.cmd

Вспомогательный скрипт, который при первом запуске создаёт символическую ссылку `gpsbabel.exe` в текущем каталоге на исполняемый файл GPSBabel, установленный в системе.

```cmd
if not exist gpsbabel.exe mklink gpsbabel.exe "C:\Program Files (x86)\gpsbabel\gpsbabel.exe"
```

**Важно:** перед запуском убедитесь, что GPSBabel установлен именно по пути `C:\Program Files (x86)\gpsbabel\gpsbabel.exe`. Если путь другой, отредактируйте скрипт.

## gpsbabel.cmd

Скрипт-обёртка для запуска `gpsbabel.exe`. Принимает аргументы командной строки, объединяет их в одну строку и передаёт GPSBabel.

### Как работает

1. Переходит в каталог `C:\Program Files (x86)\gpsbabel` через `pushd`.
2. Собирает все переданные аргументы в переменную `arg`.
3. Удаляет кавычки из строки аргументов.
4. Запускает `gpsbabel.exe` с полученными аргументами.
5. Возвращается в исходный каталог через `popd`.

### Использование

```cmd
call bin\gpsbabel.cmd "-w -t -i unicsv -f input.csv -x track,start=20200907104600,stop=20200907105000 -o kml,deficon=Speed:,floating=1,trackdirection=1,units=m -F output.kml"
```

## go.cmd

Основной скрипт обработки GPS-логов. Выполняет следующие действия:

1. **Режим `-list`** — поиск файлов по маске во входной папке и запуск обработки для каждого файла.
2. **Режим `-proc`** — обработка одного файла:
   - Конвертация исходного лога в CSV через GPSBabel.
   - Преобразование скорости из м/с в км/ч с помощью CSVfix.
   - Разделение скорости на целые и дробные части (км/ч, минуты, секунды).
   - Формирование поля `Name` для отображения данных на карте.
   - Создание итогового KML-файла.

### Использование

```cmd
go.cmd -list [маска_файлов] [начальное_время] [конечное_время]
```

**Пример:**

```cmd
go.cmd -list "*.log" 20200907104600 20200907105000
```

### Параметры

- `маска_файлов` — маска для поиска входных файлов (например, `*.log`).
- `начальное_время` — время начала трека в формате `ГГГГММДДЧЧММСС`.
- `конечное_время` — время окончания трека в формате `ГГГММДДЧЧММСС`.

### Входные и выходные данные

- **Входные данные:** GPS-логи в папке, указанной в переменной `in_path` (по умолчанию `d:\gps\in_msk\full`).
- **Выходные данные:** KML-файлы в подпапке `out` рядом с исходными логами.

### Структура каталогов

Перед запуском:

```text
project/
├─ go.cmd
├─ bin/
│  ├─ gpsbabel.cmd
│  └─ csvfix.cmd
├─ csvfix.exe
└─ gpsbabel.exe  (создаётся csvfix.cmd)
```

Во время выполнения:

```text
d:\gps\in_msk\full/
├─ 20200907_043532.log
└─ out/
   ├─ 20200907_043532_1.csv
   ├─ 20200907_043532_2.csv
   ├─ 20200907_043532_3.csv
   ├─ 20200907_043532_4.csv
   ├─ 20200907_043532_5.csv
   └─ 20200907_043532.kml
```

### Настройка путей

В скрипте `go.cmd` используются следующие переменные:

- `in_path` — путь к папке с входными файлами (по умолчанию `"d:\gps\in_msk\full"`).
- `in_file_mask` — маска входных файлов (по умолчанию `"*.log"`).
- `out_path` — имя выходной подпапки (по умолчанию `out`).

Для изменения путей отредактируйте соответствующие строки в `go.cmd`.

### Важные замечания

- Скрипт использует `setlocal EnableDelayedExpansion` для работы с переменными внутри циклов.
- Для обработки каждого файла вызывается `go.cmd proc` с передачей входного и выходного путей.
- Все промежуточные CSV-файлы сохраняются в выходной папке.
- Итоговый KML создаётся с иконками, отображающими скорость.

## Пример полного цикла

1. Установите GPSBabel в `C:\Program Files (x86)\gpsbabel`.
2. Скачайте CSVfix и поместите `csvfix.exe` в папку проекта.
3. Запустите `csvfix.cmd` для создания символической ссылки на `gpsbabel.exe`.
4. Поместите GPS-логи в папку `d:\gps\in_msk\full`.
5. Запустите:

```cmd
go.cmd -list "*.log" 20200907104600 20200907105000
```

6. Получите KML-файлы в папке `out`.
